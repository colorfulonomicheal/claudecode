# Colorful Coffee マーケティング戦略ガイド

## 1. ブランド概要

| 項目 | 内容 |
|-----|------|
| ブランド名 | Colorful Coffee |
| コンセプト | 日常に彩りを添えるスペシャルティコーヒー |
| ターゲット | 20〜40代のライフスタイルにこだわりを持つ層 |
| ブランドプロミス | 一杯のコーヒーが、あなたの一日を彩る |

## 2. エージェント構成

Colorful Coffeeの広告宣伝業務を以下の4つの専門エージェントで分担します。

### エージェント一覧

| エージェント | 役割 | 主な担当領域 |
|------------|------|------------|
| `marketing-strategist` | マーケティングストラテジスト | 全体戦略・KPI設計・予算方針 |
| `creative-director` | クリエイティブディレクター | ブランド表現・コピー・ビジュアル方針 |
| `digital-marketer` | デジタルマーケター | SNS運用・Web広告・SEO・CRM |
| `media-planner` | メディアプランナー | メディアミックス・出稿計画・予算配分 |

### エージェント連携フロー

```
marketing-strategist（全体戦略）
    ├── creative-director（クリエイティブ方針）
    ├── digital-marketer（デジタル施策）
    └── media-planner（メディア計画）
```

## 3. 活用シナリオ

### シナリオ1: 新商品ローンチキャンペーン

```bash

# Step 2: クリエイティブコンセプトを立案
claude "creative-directorエージェントを使って、
       桜ブレンドのキャンペーンクリエイティブブリーフを作成して。
       春の季節感を活かしたビジュアルとコピーを提案して"

       桜ブレンドのSNSキャンペーンとWeb広告プランを作成して。

# Step 4: メディアプランを策定
claude "media-plannerエージェントを使って、
       桜ブレンドのメディアプランを策定して。
       オンライン60%・オフライン40%の予算配分で最適化して"
```

### シナリオ2: 季節キャンペーンの統合プランニング


## 5. KPIフレームワーク

### ブランド指標
- ブランド認知率（目標: 年間+10pt）
- NPS（Net Promoter Score）（目標: 50以上）

### デジタル指標
- SNS総フォロワー数（目標: 10万人）
- エンゲージメント率（目標: 5%以上）
- Webサイト月間UU（目標: 50,000）

### 売上指標
- EC月間売上（目標: 500万円）
- 店舗来客数（目標: 月間6,000人）
- リピート率（目標: 40%以上）
- 顧客単価（目標: 1,800円）

### 広告効率指標
- ROAS（目標: 4.0倍以上）
- CPA（目標: 2,000円以下）
- CPM（目標: 500円以下）
