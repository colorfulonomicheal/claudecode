## 2. 主要ペルソナ

### ペルソナ A — 「ビジュアルコーヒーハンター」莉奈（22歳）

- 大学生/新卒社会人、女性、都市部在住
- InstagramとTikTokを1日3時間以上利用、友人と週末カフェ巡り
- ニーズ: フォトジェニックなドリンク、インスタ映えする空間、限定メニューの話題性
- 購買行動: 83%がInstagramで飲食トレンドを発見、71%がそれを元に来店決定
- 味覚傾向: ラテ・フラペ系、甘くカスタマイズ可能なドリンク

### ペルソナ B — 「スペシャルティ探求者」大輔（34歳）

- ITエンジニア、男性、週3日在宅勤務、年収600〜800万円
- 自宅にグラインダー所有、SCAJ展示会に毎年参加、フェアトレード認証を確認
- ニーズ: シングルオリジン豆の詳しい説明、バリスタとの対話、豆のサブスク
- 購買行動: シングルオリジン豆の購買は2023年に前年比27%増
- 味覚傾向: フルーティーな酸味、エチオピアやパナマ産、ブラック

### ペルソナ C — 「ウェルネスバランサー」あかね（37歳）

- マーケティング職、女性、既婚・子あり、年収450万円
- カフェイン摂取量をコントロール、「プロフィー（コーヒー×プロテイン）」の先行ユーザー
- ニーズ: 高品質デカフェ、オーガニック選択肢、成分表示の透明性
- 購買行動: デカフェ飲料市場2025年度130億円。オーガニックセグメントが最速成長
- 味覚傾向: マイルドな飲み口、ミルク系ドリンク

### ペルソナ D — 「こだわりのシニアバリスタ」田中さん（58歳）

- 会社管理職、男性、時間的・経済的余裕あり
- スペシャルティコーヒーへの感度が全年代で最も高い（来店理由「おいしいスペシャルティコーヒーがある」46.0%）
- ニーズ: 豆のクオリティと豊富な品揃え、専門スタッフとの対話
- 購買行動: 「価格以上においしい」と感じると高単価でも購入を継続

## 3. 消費トレンド分析

### 上昇トレンド

- **スペシャルティコーヒーの本格普及**: 認知率2019年42.1% → 2023年48.1%、SCAJ展示会は2024年に過去最高7万5,217人来場
- **デカフェ・ノンカフェインの品質化**: 「我慢の代替品」から「高品質な選択」へ転換、PETボトル入りデカフェ飲料市場は130億円規模
- **SNS駆動型カフェ消費**: Instagram「#カフェ」投稿2,900万件超、Z世代の71%がInstagram経由で来店決定
- **在宅バリスタ文化（フォースウェーブ）**: ホームコーヒー設備投資が継続、豆サブスク需要増加
- **サステナビリティ訴求の購買影響力化**: Z世代の78%がサステナビリティを推進するブランドを支持
- **機能性コーヒーの台頭**: 「プロフィー」が11.6%で経験済み、コラーゲン・機能性成分入りコーヒーへの関心上昇

### 下降トレンド

- **缶コーヒーの販売継続減少**: 2024年の国内消費量は前年比0.4%微減
- **差別化のない中価格帯カフェの淘汰**: 倒産が2024年度に過去最多ペース
- **ホットコーヒーのシェアの相対的縮小**: コールドブリュー・アイスコーヒーが台頭

## 4. デジタル行動パターン

| 行動 | 詳細データ | colorful coffeeへの示唆 |
|------|-----------|------------------------|
| SNS情報収集 | Z世代の71%がInstagramで飲食トレンドを発見し来店決定 | ビジュアル起点のSNSマーケティングが最優先 |
| モバイルオーダー | チェーン系カフェでの導入が進む | 待ち時間ゼロ体験がZ世代・ミレニアル層の来店ハードルを下げる |
| サブスクリプション | 月額制・回数制など多様なモデルが登場 | コーヒーサブスクと豆のオンライン定期便の二軸で設計 |
| オンライン豆購入 | ECとサブスク経由の豆販売が拡大中 | ECサイトと定期便でミレニアル・在宅勤務層を継続的に取り込む |
| TikTok・リール | 「コールドブリュー」「ラテアート」動画が若年層のコーヒー発見経路に | バリスタコンテンツ、産地紹介動画が有効 |

## 5. ペインポイントと未充足ニーズ

| ペインポイント | 対象セグメント | 現状のギャップ |
|--------------|--------------|--------------|
| デカフェの選択肢が少なく質も低い | 健康志向層・妊婦 | スペシャルティグレードのデカフェはほぼ未提供 |
| バリスタの知識不足 | ミレニアル・50代コノイスール | 産地・精製方法の質問に答えられないスタッフが多い |
| SNS映えする環境が不十分 | Z世代 | 照明・空間デザイン・ドリンクビジュアルが後回し |
| 豆サブスクやECが未整備 | 在宅バリスタ・ミレニアル男性 | 気に入った豆を帰宅後もオンラインで購入できる仕組みがない |
| サステナビリティの根拠が不透明 | Z世代・ミレニアル全般 | 第三者認証や農園情報が示されず信頼されない |
| 体験価値が価格に見合わない | Z世代・若年層全般 | コンビニへの流出が発生 |

## 6. colorful coffeeへの戦略的示唆

### 推奨ターゲット優先順位

1. **主力（コア）**: ミレニアル世代プロフェッショナル（27〜42歳） — 客単価・リピート率高、EC・サブスクで接点拡大
2. **獲得・拡大**: Z世代（15〜26歳） — SNS拡散効果最大、将来のロイヤルカスタマー育成
3. **高収益**: 50代コノイスール — ブランド信頼性の根拠となる「本物」評価

### 訴求ポイント

- **ビジュアルストーリーテリング**: 季節・産地・精製法を色彩とビジュアルで表現
- **透明性のサステナビリティ**: 農園名・認証・取引方法を明示
- **バリスタ知識の差別化**: 産地・精製方法・風味特性を語れるスタッフ
- **デカフェの本格化**: スペシャルティグレードのデカフェで空白地帯を独占
- **デジタルエコシステム**: SNS→来店→アプリ→EC→サブスクのサイクル設計
