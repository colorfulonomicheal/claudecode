# エージェント設定ガイド

## 1. サブエージェントとは

Claude Codeのサブエージェントは、特定のタスクに特化したAIエージェントです。
独立したコンテキストとツールアクセス権を持ち、専門的な作業を効率的に実行します。

## 2. サブエージェントの種類

### ビルトインエージェント
- **Explore**: コードベースの高速探索（読み取り専用）
- **Plan**: 実装計画の策定（読み取り専用）
- **General-purpose**: 汎用的なマルチステップタスク

### カスタムエージェント（このプロジェクトに含まれるもの）
- **code-reviewer**: コード品質・セキュリティレビュー
- **task-planner**: タスク分解と実装計画
- **doc-writer**: ドキュメント作成・更新

## 3. カスタムエージェントの作成方法

### ファイル配置
```
.claude/agents/       ← プロジェクト共有（git管理）
~/.claude/agents/     ← 個人用（全プロジェクト共通）
```

### エージェント定義ファイルの構造
```markdown
---
name: agent-name
description: エージェントの説明（一行）
tools: Read, Grep, Glob, Bash, Edit, Write
model: sonnet
---

システムプロンプト（エージェントへの指示）をここに記述します。
```

### frontmatterの主要フィールド

| フィールド | 説明 | 例 |
|-----------|------|-----|
| `name` | エージェント名 | `code-reviewer` |
| `description` | 説明文 | `コードレビュー専門` |
| `tools` | 使用可能ツール | `Read, Grep, Glob` |
| `model` | 使用モデル | `sonnet`, `opus`, `haiku` |

## 4. エージェントの呼び出し方

### 対話モードから
```
code-reviewerエージェントを使って、このPRをレビューして
```

### CLIから直接
```bash
claude --agent code-reviewer "src/ディレクトリのコードをレビューして"
```

## 5. 実践例

### 例1: コードレビューの自動化
```
code-reviewerエージェントを使って、直近のコミットの変更をレビューして
```

### 例2: 実装計画の策定
```
task-plannerエージェントを使って、ユーザー認証機能の実装計画を立てて
```

### 例3: ドキュメント生成
```
doc-writerエージェントを使って、src/api/のAPIドキュメントを作成して
```

## 6. エージェント設計のベストプラクティス

1. **単一責任**: 一つのエージェントに一つの役割
2. **最小権限**: 必要なツールのみ許可
3. **明確な指示**: 出力形式や判断基準を具体的に記述
4. **適切なモデル選択**: タスクの複雑さに応じてモデルを選択
